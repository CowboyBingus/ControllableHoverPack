# Controllable Hover Pack

Controllable Hover Pack now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Controllable Hover Pack's C source is in
[`src/components/controllable_hover_pack`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/controllable_hover_pack).

The standalone Lua mod (v1.8.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/ControllableHoverPack/tree/legacy) branch. Its releases and tags are unchanged.
